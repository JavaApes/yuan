## v0.5.2 · 2026-11-12

Second public preview.

- Updated home screen, research workspace and reading notes.
- Added long-term memory, scheduled tasks and follow-up instructions during execution.
- Chinese and English interfaces.
- Ad-hoc local signature, with no Developer ID certificate or Apple notarization.
- The final installer underwent a privacy scan, isolated launch and restart checks. The release validation reported 116 passing automated tests; this does not mean every external model or brokerage service has been verified.

[Download and full release notes](https://github.com/JavaApes/yuan/releases/tag/v0.5.2)

## v0.5.0 · 2026-11-07

First public preview installer on GitHub.

- Apple Silicon Mac DMG that runs independently of the development project directory.
- Investment-learning conversations, document reading, a research workspace and saved learning notes.
- Combined provider and model selection, with model availability managed in settings.
- GPT-6 models enabled by default; other OpenAI models disabled by default.
- New configurations use deep reasoning by default, with a notice about capability changes when switching models.

The preview packages use ad-hoc local signing, without Developer ID signing or Apple notarization. This repository distributes documentation and binary installers; application source code is not published.
